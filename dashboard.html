Quy Trình 6 Bước Cài Đặt & Vận Hành Chuẩn Cho Thành Viên

1

Đăng Ký & Được Super Admin Lê Hoàng Đức Duyệt Quyền

Đăng nhập tài khoản Google vào trang web này. Sau khi đăng nhập, nhắn tin cho Admin Lê Hoàng Đức để được bấm duyệt cấp quyền bản quyền. Nếu chưa được duyệt, bot sẽ bị tạm khóa không cho bắt đầu giao dịch.

2

Cài Đặt Bộ Não AI Ollama (Chạy Offline 100% Trên Máy)

Tải Ollama Cho Windows

Tải và cài đặt phần mềm Ollama để chạy mô hình AI Offline (giúp bot phân tích đa tầng, nhận định xu hướng và chế độ thị trường). Sau khi cài xong, mở CMD/PowerShell và gõ lệnh sau để tải model AI:

ollama run qwen2.5:7b
3

Tải Thư Mục Tool & Chạy File install.bat (Tự Động Cài Python 3.14 & Môi Trường)

Tải file ZIP về máy, giải nén vào thư mục riêng (khuyến nghị D:\TRADE). Nhấp đúp chuột vào file install.bat: Tool sẽ tự động kiểm tra, tự động tải và cài đặt Python 3.14 chính thức nếu máy chưa có, sau đó tự khởi tạo môi trường ảo venv và nạp toàn bộ thư viện cần thiết.

4

Đồng Bộ Giờ Sàn Bằng File Fix_Time.bat

Bắt Buộc Quyền Admin

⚠️ LƯU Ý CỰC KỲ QUAN TRỌNG: Bấm chuột phải vào file Fix_Time.bat $\rightarrow$ Chọn "Run as administrator" (Chạy với quyền Quản trị viên).

Sàn Binance kiểm tra độ lệch thời gian rất khắt khe (lệch quá 1 giây sẽ bị sàn từ chối đặt lệnh). File này sẽ tự động ép đồng hồ Windows chuẩn từng mili-giây với máy chủ Binance, đảm bảo khớp lệnh 100% trơn tru!

5

Nhấp Đúp START.bat Để Mở Giao Diện Tool Trên Máy Tính

Nhấp đúp chuột vào file START.bat. Trình duyệt web sẽ tự động mở bảng điều khiển cục bộ tại http://127.0.0.1:5000.

6

Nhập Token Web & API Binance Trực Tiếp Trên Giao Diện Tool

Không cần mở code hay sửa file thủ công, bạn nhập trực tiếp bằng 2 nút trên thanh điều khiển của Tool:

1. Bấm nút [☁️ Token Web]:

Dán Mã User Token (đã sao chép ở khung phía trên trang web này) $\rightarrow$ Bấm Lưu User Token. Dữ liệu sẽ tự động đồng bộ lên web lehoangduc.pages.dev ngay lập tức!

2. Bấm nút [🔑 API Binance]:

Điền API Key & Secret Key Futures của bạn $\rightarrow$ Bấm Lưu Binance API. Khóa API được bảo mật 100% trên máy tính của bạn (Zero-Custody).

3. Bấm nút [📱 Telegram] (Cài thông báo về điện thoại):

Điền Bot Token (tạo từ @BotFather) và Chat ID (lấy từ @userinfobot) $\rightarrow$ Bấm Gửi tin thử để kiểm tra $\rightarrow$ Bấm Lưu Telegram. Mọi lệnh vào/đóng, chốt lời TP hay cắt lỗ SL sẽ tự động nhắn tin về điện thoại của bạn tức thì!

Sau khi hoàn tất, bấm nút ▶ BẮT ĐẦU (BOT + AI). Bạn có thể mở web trên điện thoại để theo dõi bot kiếm tiền mọi lúc mọi nơi!
