Quy Trình 4 Bước Vận Hành Dành Cho Thành Viên

1

Đăng ký & Được Admin Lê Hoàng Đức Phê Duyệt

Đăng nhập tài khoản Google vào web. Sau khi đăng nhập, nhắn tin cho Admin Lê Hoàng Đức để được bấm duyệt cấp quyền truy cập. Nếu chưa được duyệt, hệ thống sẽ tạm khóa màn hình điều khiển để đảm bảo an toàn.

2

Tải Thư Mục Tool Về Máy Tính & Giải Nén

Tải file ZIP về máy, giải nén vào ổ đĩa bất kỳ (khuyến nghị để ở D:\TRADE hoặc thư mục riêng của bạn). Thư mục chứa toàn bộ thuật toán phân tích, quản trị vốn và các file chạy tự động.

3

Cấu Hình Khóa API & Mã Token Cá Nhân

Mở 2 file sau bằng Notepad để điền thông tin:

1. Mở file .env (để kết nối sàn Binance của bạn):
BINANCE_API_KEY=Điền_API_Key_Futures_Của_Bạn
BINANCE_API_SECRET=Điền_Secret_Key_Futures_Của_Bạn
2. Mở file config/settings.yaml (để đồng bộ web này):
cloud:
user_token: "Dán_Mã_Token_Ở_Khung_Phía_Trên_Vào_Đây"
4

Nhấp Đúp START.bat Để Bắt Đầu Giao Dịch

Nhấp đúp chuột vào file START.bat. Tool sẽ tự động kết nối sàn Binance, khởi động thuật toán định lượng và tự động bắn số liệu lên web lehoangduc.pages.dev/dashboard. Bạn có thể mở web trên điện thoại để quan sát bot kiếm tiền mọi lúc mọi nơi!
